# H1 — Pins: the format and the resolve pass

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hand-authored `.uidx` file can pin a child to its parent's edges, and
that child lands in the right place at any parent size — rendered, checked, and
never written back into the file.

**Architecture:** `constraints` already exists and is inert. This story makes it
mean something: four new authored-only props (`right`, `bottom`, `centerX`,
`centerY`) state the offset, a top-down pass in `@uidx/schema` computes the
coordinate the offset implies after Yoga has run, and the write-back filter
learns that a pinned coordinate is not the author's to keep.

**Tech Stack:** TypeScript, pnpm workspaces, Vitest, `@open-pencil/core` +
`@open-pencil/scene-graph` 0.14.0 (Yoga layout), Vue 3 for the viewer (not
touched by this story).

**Spec:**
[docs/superpowers/specs/2026-08-29-pins-and-constraints-design.md](../specs/2026-08-29-pins-and-constraints-design.md)
**ADR:**
[docs/decisions/0011-pins-a-child-states-its-offset.md](../../decisions/0011-pins-a-child-states-its-offset.md)

## Global Constraints

- **Node 22 for every test run.** The default `node` here is v18 and the suites
  fail with `ERR_REQUIRE_ESM`. Prefix every command:
  `export PATH="$HOME/.nvm/versions/node/v22.15.0/bin:$PATH"`.
- **Commit to `main` directly.** No worktree, no feature branch — this repo's
  story work lands on `main`.
- **Prettier is pinned and CI-checked.** Run `npx prettier --write <files>`
  before every commit.
- **Diagnostic codes are append-only.** UIDX134, UIDX135, UIDX136 are the next
  three; never renumber an existing one.
- **`known-props.ts` imports nothing.** It is a hand-maintained copy kept free
  of SDK imports so the CLI can use it; a drift test guards it.
- **The four offset props never reach the scene graph.** They are absent from
  `PROP_TABLE` on purpose. A prop with no scene field cannot be echoed back
  into the file by a reflow — that absence is the safety mechanism, not an
  oversight.
- **`SCALE` is out of scope** (ADR 0011 §3). It is rejected by `uidx check`,
  not implemented. Story H5 covers it.

- [ ] **Step 4: Implement `checkPins`**

In `packages/format/src/parse.ts`, add the method beside `checkSlotFill`:

```ts
  /**
   * What a pin may say, and where it may say it (ADR 0011 §2 and §6).
   *
   * The four offset names are repeated here rather than imported: `@uidx/schema`
   * owns `PIN_PROPS` and depends on this package, not the other way round. This
   * is the same repetition `checkInstance` makes for `component`/`overrides`,
   * and for the same reason — these are grammar questions, asked before any
   * prop table exists.
   */
  private checkPins(
    attrs: Record<string, UidxAttr>,
    parentElement: UidxElement | null,
    parentFlows: boolean,
    loc: Range,
  ): void {
    const constraints = attrs.constraints?.value
    const axis = (key: 'horizontal' | 'vertical'): string =>
      typeof constraints === 'object' && constraints !== null && !Array.isArray(constraints)
        ? ((constraints as Record<string, unknown>)[key] as string) || 'MIN'
        : 'MIN'

    const horizontal = axis('horizontal')
    const vertical = axis('vertical')
    const has = (prop: string): boolean => attrs[prop] !== undefined

    const pinned =
      horizontal !== 'MIN' ||
      vertical !== 'MIN' ||
      has('right') ||
      has('bottom') ||
      has('centerX') ||
      has('centerY')
    if (!pinned) return

    if (horizontal === 'SCALE' || vertical === 'SCALE') {
      this.error(
        CODES.PIN_SCALE_UNSUPPORTED,
        'SCALE is a ratio rather than an offset and needs fractional geometry, which UIDX ' +
          'does not have yet (ADR 0011 §3). Use STRETCH to hold both edges',
        loc,
      )
      return
    }

    // Nothing to pin to, or a parent that places this child itself. Asked
    // before the per-axis table, because "there is no box" makes every other
    // sentence about the offsets misleading.
    if (parentElement === 'Page' || parentElement === null) {
      this.error(
        CODES.PIN_NOT_ALLOWED_HERE,
        'a pin measures from a parent box, and a page is not one; put this node inside a ' +
          '<Frame> or <Component> to pin it',
        loc,
      )
      return
    }
    if (parentFlows && attrs.layoutPositioning?.value !== 'ABSOLUTE') {
      this.error(
        CODES.PIN_NOT_ALLOWED_HERE,
        "this node is placed by its parent's auto layout, so a pin has nothing to say; add " +
          'layoutPositioning="ABSOLUTE" to position it by hand',
        loc,
      )
      return
    }

    /** One axis's legality, from ADR 0011 §2's table. */
    const checkAxis = (
      constraint: string,
      near: 'x' | 'y',
      far: 'right' | 'bottom',
      centre: 'centerX' | 'centerY',
      size: 'width' | 'height',
    ): void => {
      const refuse = (prop: string): void =>
        this.error(
          CODES.PIN_GEOMETRY_CONFLICT,
          `"${prop}" is computed under a ${constraint} pin, so stating it would be a second ` +
            'answer to a question the pin already answers (ADR 0011 §2)',
          attrs[prop]?.loc ?? loc,
        )

      if (constraint === 'MIN') {
        if (has(far)) refuse(far)
        if (has(centre)) refuse(centre)
      } else if (constraint === 'MAX') {
        if (has(near)) refuse(near)
        if (has(centre)) refuse(centre)
      } else if (constraint === 'STRETCH') {
        if (has(size)) refuse(size)
        if (has(centre)) refuse(centre)
      } else if (constraint === 'CENTER') {
        if (has(near)) refuse(near)
        if (has(far)) refuse(far)
      }
    }

    checkAxis(horizontal, 'x', 'right', 'centerX', 'width')
    checkAxis(vertical, 'y', 'bottom', 'centerY', 'height')
  }
```

- [ ] **Step 3: Write `pins.ts`**

```ts
/**
 * The pin arithmetic (ADR 0011 §2), as pure functions over plain numbers.
 *
 * Deliberately free of `SceneGraph` and `UidxNode`: this is the half of pins
 * that has to be exercised exhaustively, and every test that needs a graph to
 * check a subtraction is a test nobody writes enough of. `resolvePins` in
 * `pin-pass.ts` is the half that walks a tree, and it calls this.
 *
 * Not a constraint solver. Every child resolves against a parent size that is
 * already final, so there are no cycles, no simultaneous equations and no
 * iteration — one subtraction per axis, and the walk that calls it is a single
 * top-down pass.
 */

export type PinAxis = 'MIN' | 'CENTER' | 'MAX' | 'STRETCH'

export interface Pin {
  horizontal: PinAxis
  vertical: PinAxis
  right?: number
  bottom?: number
  centerX?: number
  centerY?: number
}

export interface Box {
  x: number
  y: number
  width: number
  height: number
}

const AXES: readonly PinAxis[] = ['MIN', 'CENTER', 'MAX', 'STRETCH']

/**
 * The pin a node's attributes state, or undefined when it states none.
 *
 * Typed against `{ value: unknown }` rather than `UidxAttr` so the pass can be
 * handed a scene-side shim in a test, the way `authorship.ts` types
 * `GeometryNode` structurally and for the same reason.
 *
 * An offset with no constraint still produces a pin — `MIN` plus a `right`,
 * which `uidx check` refuses (UIDX134). Returning undefined here would make
 * the resolver silently agree with a file the checker calls wrong.
 */
export function pinFrom(attrs: Record<string, { value: unknown }> | undefined): Pin | undefined {
  if (!attrs) return undefined
  const raw = attrs.constraints?.value
  const stated =
    typeof raw === 'object' && raw !== null && !Array.isArray(raw)
      ? (raw as Record<string, unknown>)
      : {}

  const axis = (key: 'horizontal' | 'vertical'): PinAxis => {
    const value = stated[key]
    return AXES.includes(value as PinAxis) ? (value as PinAxis) : 'MIN'
  }
  const offset = (key: 'right' | 'bottom' | 'centerX' | 'centerY'): number | undefined => {
    const value = attrs[key]?.value
    return typeof value === 'number' ? value : undefined
  }

  const pin: Pin = { horizontal: axis('horizontal'), vertical: axis('vertical') }
  for (const key of ['right', 'bottom', 'centerX', 'centerY'] as const) {
    const value = offset(key)
    if (value !== undefined) pin[key] = value
  }

  const unpinned =
    pin.horizontal === 'MIN' &&
    pin.vertical === 'MIN' &&
    pin.right === undefined &&
    pin.bottom === undefined &&
    pin.centerX === undefined &&
    pin.centerY === undefined
  return unpinned ? undefined : pin
}

/** One axis, so the two cannot drift apart. `near`/`size` are the authored pair. */
function resolveAxis(
  constraint: PinAxis,
  near: number,
  size: number,
  far: number,
  centre: number,
  parent: number,
): { near: number; size: number } {
  switch (constraint) {
    case 'MAX':
      return { near: parent - far - size, size }
    case 'STRETCH':
      // A parent narrower than its own offsets would otherwise produce a
      // negative box, which the renderer draws as an inside-out rectangle.
      return { near, size: Math.max(0, parent - near - far) }
    case 'CENTER':
      return { near: (parent - size) / 2 + centre, size }
    default:
      return { near, size }
  }
}

/** The concrete box a pinned child occupies inside a parent of this size. */
export function resolvedBox(pin: Pin, box: Box, parent: { width: number; height: number }): Box {
  const h = resolveAxis(pin.horizontal, box.x, box.width, pin.right ?? 0, pin.centerX ?? 0, parent.width)
  const v = resolveAxis(pin.vertical, box.y, box.height, pin.bottom ?? 0, pin.centerY ?? 0, parent.height)
  return { x: h.near, y: v.near, width: h.size, height: v.size }
}
```

```ts
import type { Pin } from './pins.js'

/**
 * Which scene node carries which pin.
 *
 * The same species as `AddressMap`, and maintained on the same path: built
 * during construction, mutated by `applyChanges` as nodes come and go. It
 * exists because the scene node cannot answer the question — the offsets are
 * authored-only props with no scene field (ADR 0011 §2) — and because an
 * instance's generated children have no address to look up either.
 *
 * A stale entry is a silently wrong filter rather than a crash, which is why
 * the upkeep has its own tests.
 */
export interface PinMap {
  pinOf(sceneId: string): Pin | undefined
}

export interface MutablePinMap extends PinMap {
  /** Records the node's pin. `undefined` clears any pin it used to have. */
  link(sceneId: string, pin: Pin | undefined): void
  /** Forgets this node and everything beneath it, as deleting a subtree does. */
  unlink(sceneId: string): void
}

export function createPinMap(): MutablePinMap {
  const pins = new Map<string, Pin>()
  return {
    pinOf: (sceneId) => pins.get(sceneId),
    link(sceneId, pin) {
      if (pin) pins.set(sceneId, pin)
      else pins.delete(sceneId)
    },
    unlink(sceneId) {
      pins.delete(sceneId)
      // A subtree leaves as a subtree. Scene ids are addresses for authored
      // nodes, so its descendants are exactly the keys beneath this one.
      const prefix = `${sceneId}/`
      for (const key of pins.keys()) if (key.startsWith(prefix)) pins.delete(key)
    },
  }
}
```

```ts
import { computeAllLayouts } from '@open-pencil/core/layout'
import type { SceneGraph } from '@open-pencil/scene-graph'

import type { PinMap } from './pin-index.js'
import { resolvedBox } from './pins.js'

/**
 * Applies every pin under `entityId`, top-down (ADR 0011 §4).
 *
 * Top-down is not a preference. A `STRETCH` child's resolved width is what its
 * *own* pinned children measure against, so a parent must be final before its
 * children are asked — which also makes this a single pass with no iteration.
 *
 * **The one way to make this expensive** is to re-run layout for the whole
 * subtree after each pinned node resolves: that is quadratic in the child
 * count and invisible until a page is large. So layout re-runs only under a
 * node whose size actually changed, and only when it has children to reflow.
 * `pin-budget.test.ts` is what keeps that true.
 */
export function resolvePins(graph: SceneGraph, entityId: string, pins: PinMap): void {
  const walk = (parentId: string): void => {
    const parent = graph.getNode(parentId)
    if (!parent) return
    for (const childId of parent.childIds ?? []) {
      const child = graph.getNode(childId)
      if (!child) continue

      const pin = pins.pinOf(childId)
      if (pin) {
        const next = resolvedBox(
          pin,
          { x: child.x, y: child.y, width: child.width, height: child.height },
          { width: parent.width, height: parent.height },
        )
        const resized = next.width !== child.width || next.height !== child.height
        graph.updateNode(childId, next)
        // Only where the size moved, and only where there is something to
        // reflow. This is the quadratic trap, closed.
        if (resized && (child.childIds?.length ?? 0) > 0) computeAllLayouts(graph, childId)
      }
      walk(childId)
    }
  }
  walk(entityId)
}
```

`pin-pass.ts` imports nothing from `to-scene.ts` — only the SDK and Task 4's
`PinMap` — so there is no cycle. The dependency runs one way: `to-scene.ts`
imports `resolvePins`.

```ts
/**
 * Whether the pin computes this number (ADR 0011 §5).
 *
 * A *second* question beside `isDerivedPosition`, not a wider version of it.

 * pinned child is not — it is positioned by hand through an offset, and a

 *
 * The pin is read from the *document*. The offsets have no scene field to read

export function isPinnedAxis(

  prop: 'x' | 'y' | 'width' | 'height',

  if (!pin) return false

  if (prop === 'x' || prop === 'y') return axis === 'MAX' || axis === 'STRETCH' || axis === 'CENTER'
  return axis === 'STRETCH'
}
```

```mdx
## Core Intent

A card whose furniture holds its position when the card is resized. The close
control stays 16 from the right edge, the rule spans the full width minus its
margins, and the caption stays centred — none of which the file states as a
coordinate.

## Visual Contract

<Page>
  <Component name="Card/Pinned">
    <Frame name="body" width={320} height={200} cornerRadius={12}
      fills={[{ type: 'SOLID', color: { r: 0.12, g: 0.12, b: 0.14, a: 1 } }]}>
      <Text name="title" x={16} y={16} characters="Pinned" fontWeight="BOLD" />
      <Frame name="close" width={20} height={20} right={16} y={16} cornerRadius={10}
        constraints={{ horizontal: 'MAX' }}
        fills={[{ type: 'SOLID', color: { r: 1, g: 1, b: 1, a: 0.1 } }]} />
      <Frame name="rule" x={16} right={16} y={52} height={1}
        constraints={{ horizontal: 'STRETCH' }}
        fills={[{ type: 'SOLID', color: { r: 1, g: 1, b: 1, a: 0.15 } }]} />
      <Text name="caption" centerX={0} bottom={16} characters="centred, and stays that way"
        constraints={{ horizontal: 'CENTER', vertical: 'MAX' }} />
    </Frame>
  </Component>
</Page>
```
